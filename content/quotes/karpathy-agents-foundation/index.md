> "AI 领域现在最大的错误——人们急于让 Agent 跑起来，而不是先吃透底层模型
>
> 我们 2016 年在 OpenAI 就犯过这个错——代价是五年"
>
> Karpathy 真正想说的是：
>
> **第一步** → 别急着让 Agent 做所有事，先搞懂底层的模型
>
> **第二步** → Demo 很容易——产品需要十年。自动驾驶已经证明了——跳过地基，一切都会崩
>
> **第三步** → Agent 不是产品，地基才是。把地基打好——Agent 自然就长出来了
>
> "现在在做 Agent 的你——你才是最前沿。不是 OpenAI，不是 DeepMind，是你"
